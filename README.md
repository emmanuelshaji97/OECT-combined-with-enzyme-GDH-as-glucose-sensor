# OECT-Based Glucose Sensor Using GOx and GDH

This project investigates Organic Electrochemical Transistor (OECT)–based glucose sensors using Glucose Oxidase (GOx) and Glucose Dehydrogenase (GDH). The devices were fabricated with a platinum gate electrode and a dual-layer PEDOT:PSS channel for improved stability. Two sensing approaches were evaluated: enzyme immobilization on the channel and a floating-enzyme configuration in the electrolyte. The immobilization method was unstable due to enzyme wash-off, while the floating-enzyme method produced reliable and repeatable glucose responses.

Steady-state and real-time measurements confirmed successful glucose detection using both enzymes. GOx showed good performance within physiological ranges relevant to saliva and sweat, while GDH demonstrated a wider, oxygen-independent detection range, covering typical blood glucose concentrations. Preliminary observations indicate the possibility of direct electron transfer (DET) in the GDH system, requiring further study.

This work demonstrates that OECTs are strong candidates for next-generation, low-voltage, biocompatible glucose sensors suitable for wearable and flexible monitoring platforms.

## Features
- Fabricated OECTs with platinum gate and PEDOT:PSS bilayer channel  
- Comparison of GOx and GDH enzyme-based sensing  
- Steady-state and real-time electrical measurements  
- Floating-enzyme method enables stable glucose detection  
- Suitable for wearable biochemical sensor development  

## Technologies Used
- PEDOT:PSS (PH1000 + modified)
- Platinum gate electrodes
- GOx & GDH (PQQ-dependent)
- Keithley 4200A-SCS & Clarius software
- AutoCAD for chip design
- Standard cleanroom fabrication processes
